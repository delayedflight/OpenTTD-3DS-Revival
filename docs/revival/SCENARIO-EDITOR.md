# Scenario editor and New Game — r3m

Use the bottom-right switch icon to change the editor toolbar page. The starting year is on page two. Terrain, towns, industries, trees, roads and docks retain their existing actions with larger controls.

Terrain and Town Generation menus use the header pin to move to/from the upper screen. X returns a placement picker to the map; press X again to leave construction. Physical stylus dragging still needs hardware validation.

New World and New Game use native screen-sized forms. The bottom-left switch icon cycles World, Terrain and Borders. Generate is available on every page; switching pages retains choices. Heightmap setup has World and Terrain pages. Existing engine rules still disable controls that do not apply, such as snow line outside Arctic or town population in the editor.

The update does not change save formats or add music streaming. It reuses existing screen buffers. Keep the previous executable for rollback and test on a disposable scenario before editing a valuable one.
